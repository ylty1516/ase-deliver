安装并打开史莱姆

需要 Python 3.10+。Aseprite 不是编译所必需，但 open 需要它。

git clone https://github.com/ylty1516/ase-deliver.git
cd ase-deliver
py -3 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
ase-deliver.bat demo --out examples\slime --open
